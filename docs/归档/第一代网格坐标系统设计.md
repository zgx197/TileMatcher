# 第一代网格坐标系统设计

## 文档状态

本文档描述的是项目第一阶段采用的第一代网格方案。

当前状态：

- 保留
- 不再作为后续实现的主设计依据
- 主要用于记录项目早期为什么会选择固定 `2 x 2` 逻辑占位

## 是否仍有存在必要

有，但角色已经变化。

它仍然有价值的原因：

- 记录了第一代原型为什么选择 `2 x 2` 占位
- 解释了早期“半格错位整数化”的设计动机
- 方便回顾第一代原型和第二代方案之间的差异

它不再适合作为主设计依据的原因：

- 默认把麻将固定为 `2 x 2` 逻辑 footprint
- 默认把上层牌落点理解为下层四牌交点
- 更适合第一代验证，不适合当前追求的通用堆叠框架

## 当前建议

从当前阶段开始：

- 本文档保留，用于历史追踪
- 新的主设计文档切换为：
  - [通用堆叠框架与第二代网格方案](../通用堆叠框架与第二代网格方案.md)

## 第一代方案的核心特征

第一代方案的主要特征如下：

- 使用统一整数逻辑坐标 `(gx, gy, gz)`
- 每张麻将固定占用 `2 x 2` 逻辑单位
- 上层牌常通过奇数坐标落在下层四牌交点处
- 强调的是“半格错位的整数化”

这套方案适合：

- 快速原型验证
- 多层静态叠放显示
- 第一版阻挡关系实验

这套方案不再适合：

- 长方形麻将 footprint
- 由几何覆盖自然推导二支撑 / 四支撑
- 更通用的堆叠生成器

## 与第二代方案的关系

第一代方案回答的是：

- 如何用简单整数网格快速表示交点型叠放

第二代方案回答的是：

- 如何用通用几何描述表达任意矩形 footprint
- 如何通过底面完整覆盖来定义合法放置
- 如何让二支撑 / 四支撑成为几何结果，而不是写死规则

因此：

- 第一代方案是历史原型
- 第二代方案是当前主方向

## 结论

本文档建议保留，但明确降级为历史文档。

后续真正指导实现的主文档应为：

- [通用堆叠框架与第二代网格方案](../通用堆叠框架与第二代网格方案.md)
