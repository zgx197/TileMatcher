## 本机最短安装步骤

### 1. 安装 Android Studio 与 Android SDK

建议安装：

- Android Studio
- Android SDK Platform
- Android SDK Build-Tools
- Android SDK Platform-Tools
- Android Command-line Tools

建议安装后确认 SDK 目录类似于：

- `C:\Users\<你的用户名>\AppData\Local\Android\Sdk`

### 2. 安装 JDK

建议使用 JDK 17 或更高版本，并设置：

- `JAVA_HOME`

确认这两个命令能用：

```powershell
java -version
keytool -help
```

### 3. 配置环境变量

至少确保以下变量可用：

```text
ANDROID_SDK_ROOT=<Android SDK 路径>
JAVA_HOME=<JDK 路径>
```

并把下列目录加入 `PATH`：

```text
%ANDROID_SDK_ROOT%\platform-tools
%ANDROID_SDK_ROOT%\cmdline-tools\latest\bin
%JAVA_HOME%\bin
```

确认：

```powershell
adb version
java -version
keytool -help
```

### 4. 在 Godot 安装 Android Export Templates

打开 Godot 后确认：

- Editor Settings
- Export
- Android

相关 SDK、JDK、`adb` 路径都已正确指向本机安装位置。

同时确认 Godot 已安装对应版本的 Android export templates。

## 调试版导出流程

当本机工具链配置完成后，可以在 Godot 编辑器中：

1. 打开 `godot/` 工程
2. 进入 `Project -> Export`
3. 选择 `Android` 预设
4. 检查包名、版本号和输出路径
5. 选择 `Export Project`
6. 导出到：

```text
godot/build/android/TileMatcher-debug.apk
```

## 真机安装与验证

### 1. 连接手机

开启：

- 开发者选项
- USB 调试

连接后确认：

```powershell
adb devices
```

### 2. 安装 APK

```powershell
adb install -r godot/build/android/TileMatcher-debug.apk
```

### 3. 重点验证内容

建议首轮真机重点验证：

- 启动页到主页流转是否正常
- 竖屏 UI 是否完整适配
- 主页到游戏页切换是否正常
- 拖拽麻将时触摸输入是否稳定
- 通关后结算页与每日奖励页是否正常
- 重新启动应用后进度存档是否正确恢复
