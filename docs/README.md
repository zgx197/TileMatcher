# 文档目录

## 入口约定

- 文档导航规则见：[文档导航约定](./文档导航约定.md)
- `docs/` 根目录只保留当前仍然有效、仍然会持续维护的主文档
- `docs/归档/` 只保留历史方案、阶段性实施文档和已被替代的旧说明
- `docs/研发记录/` 只记录真实问题线、演进过程和排查经验
- 开始新的设计、实现或排查前，优先阅读本文件中的“当前主文档”和“当前最相关研发记录”
